# УБЕРВЫСЕКАТЕЛЬ

Плагин (VST3 Windows/macOS, AU macOS), который накопительно показывает, насколько игра попадает в сетку DAW.
Производитель в списке плагинов: Insinistra. Файлы: `Ubervysekatel.vst3`, `Ubervysekatel.component`.

Правила и числа те же, что во вкладке Rehearsal окна Insinistra в REAPER
(`Reaper projects\Scripts\rehearsal\config.lua`, `tools\rehearsal.lua`), чтобы два инструмента давали одинаковые цифры.
Детектор ударов перенесён из `insinistra_onset.jsfx`.

## Как работает
- Плагин ставится на дорожку или шину инструмента. Звук проходит через него без изменений.
- Сетка берётся из темпа и позиции DAW. Клик подключать не нужно, но играть надо под клик этой же DAW.
- Каждый удар сравнивается с ближайшей точкой сетки. Удар засчитывается, если до неё не больше 60 мс и не больше 40% шага сетки,
  иначе он попадает в счётчик «outside the grid window».
- **+ значит позади, − значит впереди**, в миллисекундах.
- TOTAL — итог с последнего сброса, LAST 8 BARS — последние 8 тактов. Показываются медиана, разброс
  (сигма без крайних 10% с каждой стороны), число ударов и оценка 0–100 (зелёный от 80, жёлтый от 60). Меньше 8 ударов — оценки нет.
- Оценка: `100 − 2·(выход из кармана, в «плохую» сторону вдвое + 0,5·разброс)`.
  Карман по умолчанию: барабаны −10…0 мс (позади — плохая сторона), бас и гитара 0…+15 мс (впереди — плохая сторона).

## Параметры
| Параметр | Что делает |
|---|---|
| Role | Drums (kit) — барабанная шина целиком; Kick, Overheads, Bass, Guitar — фильтры детектора как в JSFX |
| Grid | 1/16, 1/16T, 1/8T, 1/32; можно автоматизировать по частям песни |
| Input offset | Для живого входа: Input + Output Latency из настроек аудио DAW (Cubase: Studio → Studio Setup → Audio System). Для записанных дорожек 0 |
| Sensitivity | + ловит больше ударов, − меньше |
| Reset / Reset on play | Сброс кнопкой; с Reset on play — при каждом старте воспроизведения |
| Custom pocket, from/to | Свой карман вместо карманов по роли |

Плагин лучше ставить первым в цепочке: плагины с задержкой перед ним сдвигают удары относительно сетки.
Роль Drums (kit) новая, во вкладке Rehearsal её не было: её настройки детектора ещё надо проверить на записях.

## Установка
- **Windows:** папку `Ubervysekatel.vst3` положить в `C:\Program Files\Common Files\VST3\`.
- **macOS VST3:** `Ubervysekatel.vst3` → `~/Library/Audio/Plug-Ins/VST3/`.
- **macOS AU (Logic):** `Ubervysekatel.component` → `~/Library/Audio/Plug-Ins/Components/`.
- На Mac плагин подписан бесплатной подписью (ad-hoc). После скачивания снять метку карантина один раз:
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Ubervysekatel.component` (и так же для `.vst3`).

## Сборка
GitHub Actions (`.github/workflows/build.yml`) на каждый пуш: Windows и macOS (universal), проверка pluginval и auval.
Готовые файлы лежат в артефактах запуска. JUCE 9.0.5 подтягивается при сборке; `cmake/patch_juce.cmake` чинит
кириллическое имя в VST3 (JUCE передаёт его как ASCII). Имя хранится в `Source/UbvName.h`.
